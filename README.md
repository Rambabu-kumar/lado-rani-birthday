# Happy Birthday Risha ❤️

This is a static romantic birthday surprise website built with HTML, CSS, and vanilla JavaScript.

## Privacy note
The password-protected gallery is only a client-side visual access gate for a static site. It does not provide real security. Files in `assets/secret pic/` are still published as ordinary static assets and can be opened directly by URL or found in the page source. Remove any photos you do not want publicly accessible before publishing to GitHub Pages. A static HTML/CSS/JavaScript site cannot make these files private.

## Personal media
- `assets/front pic/` — photos used on the welcome and memories pages.
- `assets/first meet/` — first-meeting photos and videos.
- `assets/lunch date/` — lunch-date photos.
- `assets/secret pic/` — photos shown behind the gallery's visual lock; not private.

## Local preview
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.
